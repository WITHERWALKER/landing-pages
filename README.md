# Landing Pages

Repositorio de práctica donde desarrollo diferentes landing pages para mejorar y experimentar con mis habilidades en desarrollo web y diseño UI/UX.

Las landing pages de este repositorio son proyectos de prueba que me permiten trabajar en aspectos como composición visual, responsive design, animaciones, accesibilidad, SEO, rendimiento y estructura de componentes, utilizando diferentes técnicas y herramientas.

Cada carpeta corresponde a una landing page independiente.

## Proyectos

### SmileCare

Landing page para una clínica dental, enfocada en presentar sus servicios y facilitar el contacto con potenciales pacientes.

- **Stack:** Astro, Tailwind, GSAP, Lucide
- **Tipo:** Landing page

### Stroglow

Landing page para una marca de skincare, enfocada en presentar sus productos, beneficios y reseñas.

- **Stack:** Astro, Tailwind, Lucide
- **Tipo:** Landing page

## Cómo probar un proyecto

Necesitas tener instalado:

- Node.js 22 o superior
- Git

Descarga el repositorio:

```bash
git clone https://github.com/TU_USUARIO/landing-pages.git
cd landing-pages
```

O desde GitHub: **Code → Download ZIP**.

Prueba una landing:

```bash
cd smile-care
npm install
npm run dev
```

Abre `http://localhost:4321` en tu navegador.
