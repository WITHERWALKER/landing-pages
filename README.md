# Landing Pages

Colección de landing pages construidas con [Astro](https://astro.build/) y Tailwind CSS.

- `smile-care/` — Landing para clínica dental.
- `stroglow/` — Landing para tienda de skincare.

## Descargar

```bash
git clone https://github.com/TU_USUARIO/landing-pages.git
```

O desde GitHub: **Code → Download ZIP**.

## Probar una landing

```bash
cd smile-care
npm install
npm run dev
```

Abre `http://localhost:4321` en tu navegador.
